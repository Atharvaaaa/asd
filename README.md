# 🦇 Gotham Dispatch - Dinner with Siddhant Shetty

A dark, atmospheric Gotham-themed dinner invitation page for Siddhant Shetty at Sandeep on Friday at 8:00 PM.

## ✨ Features
- **Iconic Yellow Oval Batman Logo**: Authentic classic emblem and volumetric Bat-Signal in dark stormy skies.
- **Atmospheric Gotham Cityscape**: Heavy canvas rainstorm with wind drift, lightning strikes with synthesized thunder audio effects, and gothic skyscrapers.
- **Evasive "No" Button**: Escapes automatically when cursor or mobile finger approaches, triggering witty WayneTech evasion quotes.
- **Mission Accepted Dossier**: Golden authorization with Google Calendar direct sync, downloadable .ics calendar invite, and WhatsApp dispatch share.
- **Fully Responsive**: Optimized for desktop and mobile devices.

## 🚀 Deploying to Vercel (2 Easy Options)

### Option 1: Via Vercel Web Dashboard (Drag & Drop or GitHub)
1. Push this folder to your GitHub or upload it to Vercel at [vercel.com/new](https://vercel.com/new).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!

### Option 2: Via Vercel CLI
```bash
npm install -g vercel
vercel
```
